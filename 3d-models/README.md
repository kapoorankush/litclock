# LitClock case — 3D print files

Print-ready files for the LitClock case, **micro-USB power edition**: the back
cover exposes the Pi Zero 2 W's own micro-USB power port directly, so no
USB-C adapter is needed. The design derives from Arthur Gassner's
[Time Teller](https://timeteller.arthurgassner.com) case, modified for
LitClock. Licensed **CC BY** — see [NOTICE.md](../NOTICE.md) for full
attribution.

| File | What it is |
|------|------------|
| `RPIEnclosure.stl` | bottom enclosure the Pi sits in (SD-card notch incorporated) |
| `RPIEnclosureCover_microUSB_Power.stl` | back cover with a direct micro-USB power opening (notch incorporated) |
| `ScreenFrame.stl` | front frame around the e-ink panel (the author's unmodified part, included for one-stop printing) |
| `LitClock_microUSB_Power.3mf` | Bambu Studio project with all three parts arranged on two plates — open, slice, print |

Print in PLA — either slice the three STLs yourself or open the `.3mf`
project. For threaded inserts, assembly steps, and the full parts list, see
[Hardware Assembly](../docs/hardware-assembly.md).

**Prefer the original USB-C-adapter design?** The author's unmodified case
(STL + editable SolveSpace source; pairs with a female-USB-C-to-micro-USB
adapter mounted on the back) is published on
[GitHub](https://github.com/arthurgassner/timeteller/tree/main/3d-models),
[Printables](https://www.printables.com/model/1398618-timeteller-a-literature-clock),
[Thingiverse](https://www.thingiverse.com/thing:7130877), and
[MakerWorld](https://makerworld.com/en/models/1744549-timeteller-telling-the-time-through-quotes).
